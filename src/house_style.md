# House style (mined from 636 reference reports)

FORM
- Output exactly: `FINDINGS:` then the template's fields, one blank line, then `IMPRESSION:`.
- Reproduce EVERY template field label, in template order, as `LABEL:` in UPPERCASE (even if the
  template shows it in Title Case). Never drop a label. Never invent a new label.
- One blank line between top-level anatomic sections.

EDIT THE TEMPLATE - do not rewrite it
- Start from the template text. For every field the dictation does NOT mention, copy the template
  sentence UNCHANGED.
- For a field the dictation DOES mention: state the finding first as a full sentence
  ("There is ...", "There are ...", "<Finding> is present.", "<Finding> is noted."), then keep
  the still-true part of the template sentence ("No acute fracture.").
- Never leave a field reading as fully normal if the dictation names a finding for it - even a
  two-word dictation ("mild degen changes") is a finding you MUST incorporate.

ROUTING (a finding under the wrong label is penalised twice)
- Route each finding to the field whose anatomy it names:
  arthroplasty / prosthesis / hardware / screws -> the JOINTS (or equivalent) field.
  soft-tissue swelling / calcification / foreign body -> the SOFT TISSUES field.
  osteophytes / spurs / fracture / lucency / sclerosis -> the BONES / VERTEBRAE field.
  disc / canal / foramen -> the disc-level field.
- Use the wording of THIS study's body part (a foot study says "metatarsophalangeal", a hand
  study says "metacarpophalangeal").

FIDELITY
- Every finding in the dictation must appear exactly once. Do not omit any.
- Add NOTHING that is not in the dictation or the template - no extra measurements, no extra
  negatives, no comparisons, no recommendations, no "clinical correlation" unless dictated.
- Expand shorthand: degen -> degenerative, fx -> fracture, c/w -> consistent with,
  DJD -> degenerative joint disease, si joint -> sacroiliac joint. Fix obvious typos.
- Resolve placeholders (`[generic]`, `[left/right]`, `[_laterality_]`) from the study description.
- Keep negation, laterality (left/right/bilateral), severity (mild/moderate/severe) and every
  measurement + unit exactly as dictated.

IMPRESSION
- One numbered line per abnormal finding, most significant first, phrased as a full localised
  statement with severity ("Mild degenerative changes of the pelvis.", not "Degenerative changes.").
- Then a final line stating the residual normal status ("No acute fracture or dislocation.",
  "No acute cardiopulmonary abnormality.", "No acute intracranial abnormality.").
- If the dictation is entirely normal, the IMPRESSION is the template's normal summary line.
- Introduce no finding in the IMPRESSION that is not in FINDINGS.

THE EXAMPLES ARE DIFFERENT PATIENTS
- Use them only to learn wording and section routing. NEVER copy a finding, measurement, or
  non-normal sentence from an example into your report.
